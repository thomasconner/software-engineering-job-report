# Editor notes: what Thomas changes in the drafts

The column routine reads this file before every draft and updates it from the last merged column PR. Each draft is the first commit on its `column/YYYY-MM` branch, and the merged article is Thomas's edit. The difference between the two is the lesson.

## How a lesson is recorded

- One line per lesson, in the imperative ("Lead with the number, not the setup").
- Tag it with the PRs it came from and a count: `(#12, #15; seen 2)`.
- Name the kind: tone, structure, lede choice, framing, numbers, jargon, length, charts, headline.
- Quote the before → after only when it makes the lesson clearer, in a few words.
- If Thomas explained an edit in a commit message or PR comment, his reason wins over a guess.

## Promotion

- Seen once: a hint. Apply it when it fits.
- Seen in 2–3 columns: propose moving it into `docs/style-guide.md` in the same PR, and remove it from here once merged.
- A lesson that a later edit contradicts: drop it or rewrite it, and note why.

Thomas approves every change to this file by merging the PR that carries it.
